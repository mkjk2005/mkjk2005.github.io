Star Fleet: Reach the Ship

The captain has at most 30 moves to reach the ship and save Earth. Asteroids 🪨 block the way and the black hole 🕳️ ends the game.

1. Play the game

Moves: 0 / 30  ·  Score: 0  ·  Last move: –
or use the arrow keys

2. Points for each move (the reward)

Every move
Bump into asteroid / edge
Reach the ship
Fall into the black hole
Run out of moves
Progress bonus, per move
× (10 − squares from the ship)

A move's points are “every move” plus whichever other lines apply. After changing the numbers, press Reset agent so it learns from scratch.

3. Q-learning agent

Settings: exploration ε = 0.2, learning rate 0.2, discount 0.95, Q-values start at 0, ties broken at random, random seed 12345.

4. Learning curve (each point = 50 training games)

Average points per game (left axis) % of games where the ship was reached — the real goal (right axis)
